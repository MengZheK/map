# 邮件订阅与上新通知

## 1. 页面订阅（Web3Forms）

1. 打开 [Web3Forms](https://web3forms.com/)，用 `kang1390305137@gmail.com` 注册并创建 Access Key。
2. 本地：在 `.env.local` 写入：
   ```env
   VITE_WEB3FORMS_ACCESS_KEY=你的_access_key
   ```
3. 线上：在 GitHub 仓库 **Settings → Secrets and variables → Actions** 添加 Secret：
   - 名称：`VITE_WEB3FORMS_ACCESS_KEY`
   - 值：同上 Access Key  

   部署工作流会在 `npm run build` 时注入该变量。

用户提交邮箱后，你会收到一封「新订阅」通知邮件。请将邮箱加入下面的订阅者列表，以便自动群发上新通知。

## 2. 相册更新自动群发（Resend，可选）

1. 注册 [Resend](https://resend.com/)，验证发件域名或使用测试发件地址。
2. 在 GitHub Secrets 配置：
   - `RESEND_API_KEY` — API 密钥
   - `RESEND_FROM` — 例如 `Hayato Photography <notify@你的域名.com>`
   - `SUBSCRIBER_EMAILS` — 订阅者列表，逗号或换行分隔多个邮箱
3. （可选）Repository variable `SITE_URL`，例如 `https://map.robotedu.cc`

当 `public/photos/photos.json` 在 `main` 分支有推送且照片数量增加时，工作流 [.github/workflows/notify-subscribers.yml](../.github/workflows/notify-subscribers.yml) 会向 `SUBSCRIBER_EMAILS` 中的地址发送更新邮件。

本地测试脚本：

```bash
set RESEND_API_KEY=...
set RESEND_FROM=Hayato Photography <onboarding@resend.dev>
set SUBSCRIBER_EMAILS=test@example.com
set PREV_PHOTO_COUNT=250
node scripts/notify-photo-update.mjs
```

## 3. 维护建议

- 每次 Web3Forms 收到新订阅，把邮箱追加到 Secret `SUBSCRIBER_EMAILS`（或改用 Resend Audiences 后改脚本）。
- 退订：收到用户回复后，从 `SUBSCRIBER_EMAILS` 中移除对应地址。
